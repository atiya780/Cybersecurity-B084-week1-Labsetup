## ⚙️ Installation & Setup

### Step 1: Install Oracle VirtualBox

Download and install VirtualBox:

https://www.virtualbox.org/

### Step 2: Download Kali Linux

Download the official Kali Linux ISO image:

https://www.kali.org/get-kali/

### Step 3: Create a Virtual Machine

1. Open Oracle VirtualBox.
2. Click on New.
3. Enter the VM name: Kali Linux.
4. Select the Linux operating system.
5. Allocate RAM and CPU resources.
6. Create a virtual hard disk.
7. Attach the Kali Linux ISO image.

### Step 4: Install Kali Linux

1. Start the virtual machine.
2. Select Graphical Install.
3. Follow the installation instructions.
4. Configure your username and password.
5. Complete the installation.
6. Restart the virtual machine.

### Step 5: Update Kali Linux

Open the terminal and execute:

```bash
sudo apt update && sudo apt full-upgrade -y
```
